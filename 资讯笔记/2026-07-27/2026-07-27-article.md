# 2.8万亿参数权重全放出来了，但它没敢说自己是最强的

一个模型能力再强，如果只能通过付费 API 调用，企业想把它接入自己的核心业务系统，数据始终要经过别人的服务器——医疗、金融这类对数据出境敏感的行业，宁可放弃更强的模型，也要用一个能部署在自己机房里的次优选择。这道门槛，比模型好不好用更难迈过去。此前，一款 2.8 万亿参数的旗舰模型已经发布，能力已经追近头部闭源模型，但当时只开放了 API 调用，权重迟迟没有放出来，想自己部署的团队只能干等。

月之暗面（Moonshot AI）在 Hugging Face 正式开放 Kimi K3 完整模型权重下载，采用 Modified MIT 许可证，是全球首个开源的 3 万亿参数级别模型。

## 2.8 万亿参数，但干活时只用一小部分

Kimi K3 的参数规模达到 2.8 万亿，但这不代表推理时要真的调用全部参数——它是一个混合专家（MoE）模型，896 个专家里每次只激活 16 个，实际参与计算的激活参数约 500 亿。简单来说，模型"知识储备"很大，但"干活"时只调用其中一小部分，这是 MoE 架构用来平衡能力和推理成本的常见思路。权重体积经过 MXFP4 量化压缩到约 1.4TB，支持 100 万 token 的上下文窗口。

## 登顶的是子榜单，不是全面反超

在 Arena.ai 的前端代码竞技场评测中，Kimi K3 以 76% 的胜率登顶，Terminal-Bench 2.1 测试也拿到了 88.3 分。不过需要说明的是，月之暗面自己也承认，K3 在综合性能上目前仍落后于 Claude Fable 5 和 GPT-5.6 Sol——这次登顶，是在前端代码这个具体子项上的突破，而不是全面反超闭源旗舰。简单来说，K3 赢的是一场单项比赛，不是把整个赛季的冠军都拿下了。

这是继 DeepSeek 之后，又一次"开源权重追平/逼近闭源前沿"的标志性事件——尤其是 Modified MIT 许可证意味着企业可以免费商用、本地部署，不用再为了数据隐私和推理成本在"用 API"和"自己部署"之间做妥协。对 OpenAI、Anthropic 这类靠模型能力溢价定价的闭源厂商来说，这类开源旗舰模型每往前挪一步，都是在压缩它们的定价空间。

从"能力强但只能远程调用"，到"权重完全开放、企业可以自己部署"，Kimi K3 这次补上的不是能力短板，而是"用不用得起、放不放得下心"这道更实际的门槛。至于它到底比闭源旗舰强还是弱，一个子榜单的登顶还说明不了全部问题——但这道题，已经轮到闭源厂商开始认真回答了。
