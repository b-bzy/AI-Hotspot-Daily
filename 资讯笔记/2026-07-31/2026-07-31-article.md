# 从1.25秒到0.70秒：省下的半秒钟，决定了你愿不愿意继续跟AI说话

打语音电话给客服机器人，提问之后卡在那里的那零点几秒沉默，是所有实时语音 AI 最难藏住的破绽——人类对话里，超过 1 秒的停顿就会让人觉得"卡壳了""没听懂"，而这零点几秒的延迟，恰恰是从"语音识别"到"大模型思考"再到"语音合成"这条链路里，最难压缩的部分。

xAI 推出新一代语音模型 Grok Voice Think Fast 2.0，在语音推理、转写准确率和对话流畅度上升级，已上线 API 与 Voice Agent Builder。这个"超越 OpenAI 和 Google 同类产品"的说法，不只是官方自己说的——独立评测机构给出的具体名次和分数，也印证了这一点。

## 唯一一个首响时间跌破1秒的模型

最直观的进步在延迟上——首个语音响应延迟从上一代的 1.25 秒，压缩到了约 0.70 秒。第三方评测机构 Artificial Analysis 的独立测试显示，这个成绩让它成为其 Speech to Speech Index 榜单前五名里，唯一一个平均首响时间低于 1 秒的模型；在这份榜单上，Think Fast 2.0 的高推理版本以 82.9% 的成绩排在第二位，前代 Think Fast 1.0 是 75.7%。另外在 Tau Voice 这项衡量 Agent 能力的评测里，它排到了第一，得分 56.5%。

## "用得更省"不等于"算得更便宜"

官方给出的另一个数据是，推理所需的 token 用量减少了约 60%。不过这里有个细节值得说清楚：token 用量下降，不完全等同于"用起来更便宜"——因为这一代模型本身能力更强、单价结构也发生了变化，官方公布的新定价是每分钟语音 0.08 美元、每千文本 token 0.004 美元，跟上一代相比，实际到手成本是涨是降，取决于具体使用场景下省下的 token 数能不能抵消单价的变化。简单来说，"完成一次任务花的 token 变少了"和"每个 token 的价格变便宜了"是两件不完全一样的事，不能简单划等号。

8 月 5 日起，xAI 默认的语音模型别名 grok-voice-latest 将自动切换到这个新版本——这意味着现有接入方不用手动升级，系统会自动帮你换上新模型。实时语音模型这场竞赛，正在从"能不能听懂""说得像不像人"这类基础能力比拼，转向延迟和定价这类更贴近实际部署成本的维度较量。

从 1.25 秒到 0.70 秒，省下来的这半秒钟，决定的不是"AI 聪不聪明"，而是"人愿不愿意继续跟它说下去"。这场实时语音的竞速，拼到最后，拼的可能就是这零点几秒的耐心阈值。
