# 今日 GitHub AI 热点：从安全技能包到代码评审工具

> 今天的 GitHub Trending 日榜里，AI 相关项目集中在两端：给 AI 编程智能体配套的专业工具，以及一个运行多年的经典深度学习项目，分别覆盖安全研究、代码评审、生成模型三个方向。

---

## 1. reverse-skill — 面向 AI 编程智能体的逆向工程与渗透测试技能路由包

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 10.9k | 335 | PowerShell | MIT |

reverse-skill 要解决的问题很具体：当 Claude Code、Codex CLI、Cursor 这类 AI 编程智能体遇到 APK、二进制文件、加密的前端 JS 或 CTF 题目时，本身并不知道该用 jadx、apktool、Frida 还是 IDA。这个项目提供一层路由逻辑，把智能体引导到对应场景的方法论和工具链上，避免每次靠猜测执行命令。

项目按场景拆成约 20 个技能模块，覆盖 APK/iOS 分析、二进制逆向、.NET、前端 JS 逆向、恶意软件分析、渗透测试、固件安全、EDR 绕过等方向，每类场景对应固定工具索引和执行流程，动作前先做授权范围核对，产出统一格式报告。内置 CTF-Sandbox-Orchestrator 子模块另打包了 40 多个 CTF 专项技能。

适合用 AI 编程智能体做授权渗透测试或参加 CTF 比赛的安全研究者，给智能体一套可复用打法，而不是临场现凑。

🔗 项目地址：https://github.com/zhaoxuya520/reverse-skill

## 2. tuicr — 给 AI 编程智能体准备的终端代码评审工具

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 2.2k | 335 | Rust | MIT |

在终端里评审代码，此前大多只能用 `git diff` 看差异，或用 `gh pr review` 做整体 approve/comment，没法逐行留评论。tuicr 提供了 GitHub 风格的连续 diff 视图，用 vim 按键在终端滚动浏览所有改动文件，支持行级、区间级、文件级、整体级四种评论，评审记录按会话持久化保存。

和 `gh pr review` 相比，tuicr 能把完整的行内评审推送到 GitHub 和 GitLab，兼容 git、jj、Mercurial 三种版本管理工具。它区别于同类工具的地方在于"给智能体导出"：按 `y` 键把带文件名和行号锚点的编号评论复制为结构化 Markdown，粘贴给 Claude、Codex、Cursor 等编程智能体去逐条修复，把"人工评审"和"智能体改代码"连了起来。

适合习惯终端工作流、且经常评审 AI 智能体生成代码的开发者，用它可以把评审意见直接转化成智能体能执行的任务清单。

🔗 项目地址：https://github.com/agavra/tuicr

## 3. deepfakes/faceswap — 用深度学习做换脸的开源项目

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 57k | 93 | Python | GPL-3.0 |

FaceSwap 用深度学习模型识别并替换图片、视频中的人脸：先从素材中提取人脸，用两组人脸数据训练模型，再用训练好的模型转换目标素材，另提供图形界面版本。运行需要支持 CUDA 的显卡，Linux 上的 AMD 显卡可通过 ROCm 支持。

项目已维护多年，累计 57k star，社区活跃度靠 Discord 和论坛支撑。README 里有一段明确的伦理声明：不用于制作不当内容，不用于未经同意更换他人面部，开发者对不正当用途采取零容忍态度；项目定位是让没有深度学习研究背景的人也能上手实验生成模型技术。这也是它区别于同类"一键换脸"应用的地方——代码需要自己搭建训练流程，不是开箱即用的产品。

适合想动手了解生成模型训练流程、且认同项目伦理声明的学习者和研究者，不适合直接部署做面向公众的换脸服务。

🔗 项目地址：https://github.com/deepfakes/faceswap

## 今日观察

三个项目分属不同时间线：reverse-skill 和 tuicr 是刚适配"AI 编程智能体"生态的新工具，靠给智能体提供结构化的技能路由或评审意见站稳位置；faceswap 则是运行多年的经典深度学习项目，靠公开的伦理声明维持社区活跃度。老项目和新工具同时上榜，说明 GitHub Trending 上"AI 相关"的范围，已从模型训练延伸到开发者工作流的具体环节。
