# 今日 GitHub 热点：AI 智能体走进协作与建站工具

> 今天的 GitHub 热榜上，AI 相关项目开始跳出聊天助手的形态。三个项目分别把智能体嵌入团队协作、建站编辑器和前端设计审查环节，值得关注。

---

## 1. Buzz — 人类与 AI 智能体共用同一套协作系统

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 13.5k | 1,710 | Rust | Apache-2.0 |

多数团队协作工具只服务人类，AI 智能体想参与往往要靠外挂机器人。Buzz 由移动支付公司 Block（原 Square）的团队开发，把频道消息、代码补丁、CI 结果、审批记录统一写成一份基于 Nostr 协议的签名事件日志，人和智能体用同一套身份体系和审计记录。

它底层是用 Rust 写的 Nostr 中继（relay），每条事件都带签名，智能体拥有自己的频道成员身份和权限范围，不是共享一个万能 token。项目提供 buzz-cli 和 ACP↔MCP 桥接层，可以对接 Goose、Codex、Claude Code 等智能体运行时，让它们打开仓库、提交补丁、参与代码审查。

适合已经在生产环境里跑多个 AI 智能体、需要统一权限和审计边界的工程团队。项目自己的功能表把移动客户端、推送通知等标为"尚未完成"，仍在快速迭代。

🔗 项目地址：https://github.com/block/buzz

## 2. Instatic — 内置 AI 智能体的自托管建站 CMS

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 5.8k | 888 | TypeScript | MIT |

Instatic 想解决的是建站工具链太碎的问题：可视化编辑器、内容管理、发布器全部塞进一个 Bun 服务里，用 SQLite 或 Postgres 存数据，输出的是可以直接读 view-source 的纯 HTML 和 CSS，不带任何前端框架运行时。

区别于普通拖拽建站工具，Instatic 内置了一个能真正编辑页面的 AI 智能体：描述需求后，它在画布上生成可编辑的节点，而不是截图或一堆代码。Site 模式提供 35 个工具，Content 模式提供 15 个工具，模型不锁定厂商，可以接 Claude、OpenAI、OpenRouter 或本地部署的 Ollama。

适合想自建站、又不想为一堆 SaaS 服务分别付费的开发者。项目目前是 0.0.x 版本，作者在 README 里写明 API 和工作流程在 1.0 前还会调整。

🔗 项目地址：https://github.com/CoreBunch/Instatic

## 3. Impeccable — 给 AI 编程智能体用的前端设计规范

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 50.8k | 413 | JavaScript | Apache-2.0 |

AI 编程智能体生成的前端页面经常撞脸：无衬线字体、紫蓝渐变、卡片套卡片、彩色背景配灰字。Impeccable 是一套可以装进 Claude Code、Cursor、Codex 等工具的技能包，用命令和检测规则去约束这些惯用套路。

项目提供 23 个命令，比如 audit（技术质量检查）、critique（设计评审）、polish（上线前打磨），再配合 60 条不依赖大模型、纯规则判断的检测器和浏览器扩展做实时反馈。它的起点是 Anthropic 官方的 frontend-design 技能，在此基础上做了扩展。

适合团队里没有专职设计师、但不希望 AI 生成界面千篇一律的场景，目前支持 Claude Code、Cursor、Gemini CLI、Codex CLI 等多种工具。

🔗 项目地址：https://github.com/pbakaus/impeccable

## 今日观察

三个项目的共同点是，AI 智能体不再局限于对话框，而是被放进了具体的生产环节：团队协作的审计日志、建站工具的画布、前端交付前的质量检查，分别对应协作者、执行者和审查者三种角色。
