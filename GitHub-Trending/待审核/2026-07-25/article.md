# 今日 GitHub AI 热点：智能体浏览器与大模型教程同时登榜

> 今天的 GitHub Trending 日榜上，AI 相关项目呈现两个方向：一端是刚起步、增长迅猛的智能体工具，另一端是面向开发者和学习者的成熟内容与产品。三个项目分别代表了智能体浏览自动化、数据库场景下的 AI 辅助，以及大模型知识的系统化教学。

---

## 1. ego lite — 让 AI 智能体和你共用同一个浏览器

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 2.7k | 880 | JavaScript | MIT |

ego lite 要解决的问题很具体：AI 智能体做浏览器自动化时，通常需要单独起一个浏览器实例来驱动，登录状态很难带过去，人和智能体也会抢占同一批标签页。ego lite 把这个前提改掉，做成一个浏览器，人和智能体在里面各有各的空间——用户照常浏览，智能体在自己的 Space 里后台跑任务，互不干扰，还能随时接管或终止智能体正在跑的任务。

技术上的差异点在于交互方式：ego lite 把浏览器能力包装成 JavaScript 函数直接暴露给智能体调用，让智能体写代码一次性完成多步操作，而不是常见的"发一条命令、看一次结果、再发下一条"的 CLI 循环。项目在四个复杂浏览器自动化任务上和 Vercel 的 agent-browser 做了对比测试，结果显示 ego lite 完成任务的速度最多快 2.5 倍，消耗的 token 也更少。目前该项目通过 `ego-browser` skill 对接 Claude Code、Codex、Cursor 等主流智能体 CLI，可以让同一个智能体同时在多个 Space 里并行处理任务。

适合已经在用 Claude Code、Codex 一类智能体做浏览器操作、又不想因此丢失登录状态或抢占自己标签页的开发者。目前仅支持 macOS，Windows 和 Linux 在路线图上。

🔗 项目地址：https://github.com/citrolabs/ego-lite

## 2. dive-into-llms — 上海交大出品的大模型编程实践教程

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 45.1k | 328 | Jupyter Notebook | — |

《动手学大模型》是一套面向初学者的大模型编程实践教程，脱胎于上海交通大学《自然语言处理前沿技术》《人工智能安全技术》两门课程的讲义，公益性质、完全免费。它解决的是"大模型概念多但缺少可运行代码"的入门痛点，每一章都配套课件 PDF、图文教程和可直接跑的 Jupyter Notebook 脚本。

内容目前覆盖 11 个主题，从模型微调与部署、提示学习与思维链，到知识编辑、数学推理蒸馏、语言模型水印、越狱攻击、大模型隐写、多模态模型，再到 GUI 智能体、智能体安全和基于 PPO 的 RLHF 对齐实验，覆盖面从工程实践延伸到安全对抗这类近期讨论较多的方向。仓库没有附带开源协议声明，README 中说明内容来自贡献者的个人经验与研究积累整理而成。

适合刚接触大模型、需要一套能直接跑起来的中文实践教程的学生和自学者，也适合高校课程作为配套实验材料参考。

🔗 项目地址：https://github.com/Lordog/dive-into-llms

## 3. Chat2DB — 把 SQL 工作台接上你自己的 AI 模型

| 总 Star | 24h 新增 | 主语言 | 协议 |
|---|---|---|---|
| 26.4k | 82 | Java | Apache-2.0（5.3.0 起附加条款） |

Chat2DB 是一款跨平台数据库客户端，本地运行，支持 MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、MongoDB、Redis 等 30 余种数据库。它要解决的问题是：写 SQL 的人不一定熟悉每种数据库的语法细节，AI 助手能用自然语言把"生成、解释、优化 SQL"这几步接管过来，同时保留一个完整的 SQL 编辑、执行、历史记录工作台。

和纯 AI 生成 SQL 的工具不同，Chat2DB 的 AI 助手需要用户自带模型接入，而不是内置固定的模型服务，这意味着企业可以用自己已有的模型账号，不必额外为 AI 功能付费。项目还提供了支持 MCP 协议的开源 CLI，可以作为智能体调用数据库的另一条路径。需要说明的是，Chat2DB 从 5.3.0 版本起改为基于 Apache License 2.0 附加额外条款的源码可用协议，早期版本仍是纯 Apache-2.0。

适合需要跨多种数据库切换、又想用自然语言辅助写 SQL 的开发者和数据分析师，尤其是已经有自己模型账号、不想被单一 AI 厂商锁定的团队。

🔗 项目地址：https://github.com/OtterMind/Chat2DB
